# تطبيق «بين الشفتات» (النموذج الأولي)

نموذج أولي عملي لتطبيق ويب موجّه لتنظيم وتنسيق تسليم المهام والحجوزات والنواقص والتبليغات بين **الشفت الصباحي** و**الشفت المسائي** في المتاجر والمكتبات والصيدليات.

---

## 🌟 المشكلة والحل

- **المشكلة:** الحجوزات ونواقص البضائع والتبليغات تتشتت وتضيع بين الأوراق والملاحظات ورسائل المحادثات غير المنظمة، ولا يعرف موظف الشفت القادم من استلم كل طلب أو ما تم إنجازه.
- **الحل:** مساحة عمل مشتركة وبسيطة تُظهر بوضوح:
  1. المطلوب بدقة ونوعه (حجز، نقص بضاعة، تبليغ).
  2. أولويته وموعده (عادي / مستعجل).
  3. كاتب الطلب وتوقيته والشفت الذي أضيف فيه.
  4. من استلم متابعته وحالته اللحظية (جديد، قيد المتابعة/التجهيز، جاهز للاستلام، مكتمل/مُسلّم).
  5. ميزة مخصصة لتسليم الشفت: «باقي من الشفت السابق».

---

## 🚀 طريقة تشغيل النموذج وتجربته

النموذج مبني باستخدام تقنيات الويب القياسية الخفيفة (HTML5 + CSS3 + Vanilla JavaScript) ولا يحتاج لأي تثبيت أو إعداد معقد:

### الطريقة الأولى: عبر المتصفح مباشرة (أسهل طريقة)
1. افتح المجلد: `c:\Users\NSR.AS\OneDrive\Desktop\فايل`
2. اضغط مرتين على ملف `index.html` ليفتح مباشرة في متصفحك المفضل (Chrome, Edge, Safari, Firefox).

### الطريقة الثانية: عبر خادم محلي (Local Server)
إذا أردت تجربة التطبيق عبر شبكة محلية أو عبر منفذ محلي:
```powershell
python -m http.server 8080
```
ثم افتح الرابط في المتصفح:
[http://localhost:8080/index.html](http://localhost:8080/index.html)

## 🔍 سيناريوهات لتجربة جميع المميزات

1. **تجربة تبديل الموظف والشفت:**
   - من الشريط العلوي، اختر الموظف (مثلاً: أحمد الحكيم أو سارة العلي).
   - بدّل بين **الشفت الصباحي ☀️** و**الشفت المسائي 🌙**، ولاحظ كيف يتفاعل التطبيق تلقائياً مع تسليم المهام.

2. **تجربة استلام طلب («أني أتابعه»):**
   - في أي طلب جديد (مثل: «توفير أكياس تغليف»)، اضغط على **«✋ أني أتابعه»**.
   - يتحول الطلب فوراً إلى «قيد المتابعة»، ويُسجَّل اسمك كمسؤول عن الطلب، ويختفي زر الاستلام للجميع.

3. **تجربة إنجاز الطلب وإعادة الفتح:**
   - بعد الاستلام، اضغط على **«✅ تم التوفير»** أو **«📦 جاهز للاستلام»** (للحجوزات).
   - إذا تم إكمال طلب بالخطأ، يتوفر زر **«🔄 إعادة فتح الطلب»** لإعادته للمتابعة.
   - إذا استلمت طلباً وأردت التراجع عنه للزملاء، يتوفر زر **«↩️ إلغاء استلامي»**.

4. **تجربة «باقي من الشفت السابق»:**
   - وأنت في الشفت الصباحي، اضغط على زر شريط التسليم: **«عرض مهام الشفت السابق»**.
   - ستظهر لك فقط الطلبات المفتوحة المنقولة من الشفت المسائي، مرتبة بحيث يظهر **المستعجل أولاً**.

5. **تجربة فلتر «طلباتي»:**
   - اضغط على زر **«👤 طلباتي فقط»** لتصفية الشاشة فوراً وإظهار الطلبات المسندة للموظف المختار فقط.

6. **تجربة إضافة وتعديل وحذف طلب:**
   - اضغط على **«+ إضافة طلب جديد»**، جرّب إضافة حجز لزبون أو نقص في البضاعة.
   - لاحظ التسجيل التلقائي لاسم الكاتب والشفت الحالي.
   - يمكنك تعديل أي طلب عبر زر **«✏️ تعديل»** أو حذفه مع نافذة تأكيد عبر زر **«🗑️»**.

7. **تجربة التبليغات:**
   - انتقل لتبويب **«📢 التبليغات»**.
   - اضغط على **«👍 اطّلعت»** على تبليغ تغيير وقت الدوام، ولاحظ ظهور اسمك مباشرة ضمن قائمة من اطّلعوا على التبليغ.

8. **تجربة الحفظ بعد التحديث:**
   - أجرِ أي تعديل، ثم حدّث الصفحة (F5). ستبقى كافة التعديلات كما هي محفوظة داخل المتصفح (`localStorage`).

## 📋 مقارنة: ما يعمل حالياً وما يحتاج ربطاً لاحقاً

| الخاصية | في النموذج الحالي (Prototype) | للتطبيق المشترك النهائي (Production) |
|---|---|---|
| **حفظ البيانات** | حفظ محلي لحظي في المتصفح (`localStorage`). | قاعدة بيانات سحابية (مثل Supabase أو PostgreSQL أو Firebase) ليتزامن العمل لحظياً بين أجهزة جميع الموظفين. |
| **هوية الموظف** | اختيار سريع من قائمة موظفين تجريبية دون كلمة سر. | تسجيل دخول حقيقي (حساب وكلمة سر أو رمز PIN سريع لكل موظف / بصمة). |
| **التزامن الحي** | تحديث يدوي / على نفس الجهاز. | تحديث فوري (WebSockets / Server-Sent Events) لتظهر التحديثات فوراً على شاشات باقي الموظفين دون إعادة تحميل الصفحة. |
| **الإشعارات** | تنبيهات بصرية داخل التطبيق (Toasts). | إشعارات هاتف (Push Notifications) أو رسائل تنبيهية عند وجود طلب مستعجل جداً. |
| **سجل التدقيق (Audit Log)** | تسجيل اسم الكاتب والمسؤول الحالي. | سجل تاريخي كامل يسجل وقت كل خطوة (من أنشأ، من غيّر الحالة، ومتى تم التسليم بدقة). |

## 🎨 البنية البرمجية للمشروع

- **`index.html`**: الهيكل الدلالي للواجهة العربية بالكامل من اليمين لليسار (RTL) متوافق مع معايير الوصول والـ SEO.
- **`style.css`**: نظام تصميم متكامل بالمتغيرات (CSS Variables)، يدعم الموبايل أولاً وخط تجوال (Tajawal) مع تفاعلات سلسة وظلال هادئة.
- **`app.js`**: إدارة حالة التطبيق (State Store)، الفلاتر، دورة حياة الطلبات والحجوزات والتبليغات، وحفظ وتحديث الـ LocalStorage.
